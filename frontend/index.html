multitenant-crm

Admin console for the multi-tenant SaaS backend. Onboard a tenant, then log in as it.

1. Onboard a tenant platform admin

Creates a tenant and its first ADMIN user. Needs the platform-admin credentials (see application.yml / .env).

2. Log in

Logs in as a tenant user and opens the dashboard for that tenant.
